## Mapping audit

The installed direct-VPP API may send a whole command when changing an individual active parameter.
The existing integration transport may retry a write after a lost response. Existing button autorepeat is not acceptable for an expiring intent.
Mode 8 A6/A7 definitions differ between revisions. The older manufacturer KB describes A6 duration / A7 remote-control timeout. The manufacturer-authored protocol V001.02 (public mirror, Mode 8 table, pp. 70–71) describes A6 WaitTimeout / A7 NextMotion, A1 execution mode (1 = interrupt), LSW-first 32-bit PV/battery targets, negative battery target for charging. Readback A6/A7 at 1A6/1A7 agrees with the installed integration diagnostic labels. A6 is NOT a guaranteed maximum execution duration. The matching V001.00 document and live protocol reading were verified 25.11; see addendum below. Native expiration remains unverified.

2. Review patch and exact installed hashes; back up HA and vendor sources. Apply only with separate authorization, keep main/production unchanged until reviewed.
