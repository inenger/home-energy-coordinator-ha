## Co ještě nelze označit za hotové

1. Automatická 14denní fyzická purge `night_samples` čeká na minimálně 12h interval. První tři souhrny existují, jsou immutable a byly ověřeny vůči původním datům, ale fyzický mazací krok teprve nastane při příštím oprávněném maintenance běhu.
2. Nová celá noc provozu 0.6.34 a čerstvý chladný scénář neproběhly; historické as-of a syntetické testy jsou důkazem logiky, nikoli výsledku budoucího režimu na reálném hardwaru.
3. Staré blokátory ostrého řízení (výkonové limity, nezávislý HW timeout, SolaX fyzický test) **nejsou** tímto vydáním uzavřeny. HEC LIVE stále zůstává odpojeno.
4. Externí Google Drive backup může mít vlastní nedostatek kapacity; zde provedená nativní záloha nenahrazuje ověřený off-site restore.

Tato poznámka je dodatečná **dokumentační evidence**. Nepřepíná stav runtime ani nezavádí nový Docker build nebo vyžadovanou fyzickou akci.
